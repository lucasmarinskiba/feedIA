# Product Validation Checklist

**Purpose**: Validate product-market fit in 90 days (customer demand, retention, pricing, founder-independent).

**Timeline**: 90 days.

**Invokes**: PMF Validation SKILL (Olsen 6-step + Ries BML + Fitzpatrick Mom Test + Collins Hedgehog + Ariely psychology).

## Section 3: CUSTOMER DISCOVERY (Days 15-28) — MOM TEST

**Input**: Interview 5-8 target customers. Behavioral questions. Commitment signals.

### Discovery Interview Script (30 minutes)

**Intro** (2 min):

> "I'm building task management for ADHD-focused teams. Not selling today — learning from you. Got 30 min?"

**Discovery** (15 min):

1. "What's the hardest part about task management right now?" (open)
2. "How are you solving this now?" (current workaround)
3. "When was the last time you switched tools?" (timeline signal)
4. "If you could fix ONE thing, what?" (priority)
5. "What do you look for in a new tool?" (evaluation criteria)

**Commitment signals** (10 min):

- Explicit: "Would you try this if built?" (yes/no)
- Monetary: "Would you pay $50/mo?" (yes/no)
- Effort: "Can I follow up next week?" (low-effort yes)

**Close** (3 min):

> "Thanks. You've been huge. Any other people I should talk to?"

### Discovery Results (Interview 5-8 customers)

| Name   | Pain Point             | Current Solution    | Would Try? | Would Pay? | Urgency | Notes                     |
| ------ | ---------------------- | ------------------- | ---------- | ---------- | ------- | ------------------------- |
| Sarah  | 20 hrs/week admin      | Asana + paper       | Yes        | Yes $50    | High    | Needs tool by month 1     |
| Marcus | Notifications overload | Gmail + spreadsheet | Yes        | Maybe      | Medium  | Technical, but evaluating |
|        |                        |                     |            |            |         |                           |
|        |                        |                     |            |            |         |                           |

**Success criteria**:

- ☐ 5-8 interviews completed
- ☐ Consistent pain emerges (not random)
- ☐ 5+ willing to try (explicit commitment)
- ☐ 2-3 willing to pay (monetary commitment)
- ☐ 3+ high urgency (timeline signal)

**Outcome**: Customer profile + opportunity validated.

### Positioning Tests (Weeks 3-4)

**Test 1**: Pitch value prop to 5 customers from discovery → Do 4/5 remember it + can repeat back?

- ☐ Yes (sticky) → Move forward
- ☐ No (confusing) → Rewrite, test again

**Test 2**: Ask 5 customers, "Would this solve your pain?" → Do 4/5 say yes?

- ☐ Yes (resonates) → Move forward
- ☐ No (misses) → Reposition, test again

## Section 7: TESTING + LEARNING (Days 57-74)

**Input**: Launch prototype. Observe. Measure.

### Qualitative Testing (Weeks 8-10)

**Activities**:

- Weekly check-in calls (5-8 customers, open questions)
- Observe workflow (watch them use it, don't guide)
- Why questions (why use X feature? Why stop using Y?)
- Iterate (weekly feature updates based on feedback)

**Template check-in call**:

> "How's it going? What's working? What's frustrating? What's missing?"

**Do NOT ask**:

> "Do you like it?" (leading, invites politeness)

**Do ask**:

> "Show me how you'd accomplish X?" (observe behavior)

### Quantitative Tracking (Weeks 8-10)

**Dashboard** (track daily):

| Metric                          | Day 1 | Day 3 | Day 7 | Day 14 | Goal    |
| ------------------------------- | ----- | ----- | ----- | ------ | ------- |
| Users activated                 |       |       |       |        | 70%+    |
| Retention                       | 100%  | 85%   | 70%   | 60%    | 60%+    |
| Core feature usage (focus mode) |       |       |       |        | 80%+    |
| NPS (survey week 2)             |       |       |       |        | 50+     |
| Churn reason                    |       |       |       |        | <10%/mo |

**Tools** (pick one):

- Google Analytics (free, tracks activation + retention)
- Amplitude (free tier, cohort analysis)
- Mixpanel (free tier, event tracking)
- Custom dashboard (Excel if small)

### Analysis (Week 10)

**Retention curve analysis**:

- Plot day 1, 3, 7, 14, 30 retention
- If curve flat or improving → good signal
- If curve declining → engagement problem

**Cohort analysis**:

- Compare Week 1 cohort vs Week 2 cohort retention
- If same curve → system stable
- If different curve → onboarding improving or regressing

**Feature usage**:

- Which features used most? (focus mode? priorities?)
- Which features ignored? (recurring tasks? integrations?)
- Iterate: double down winners, remove ignored

## Section 8: PIVOT VS PERSIST DECISION (Days 75-84)

**Input**: Data + feedback → decide.

### Persist Criteria (All Must Be True)

- ☐ Retention >60% day 7 (sticky behavior)
- ☐ Cohort curves flat or improving (not declining week 2+)
- ☐ NPS >50 (customers enthusiastic)
- ☐ Customers paying (even if discounted) without hesitation
- ☐ Churn <10%/month (sustainable)

**All true?** → PERSIST → Move to scaling (day 85+).

**Any false?** → PIVOT.

### Pivot Options (If Persisting Not Viable)

| Pivot Type           | Change                         | Example                                                |
| -------------------- | ------------------------------ | ------------------------------------------------------ |
| **Zoom-in**          | Feature becomes product        | "Focus mode app" (instead of full task manager)        |
| **Zoom-out**         | Problem broader                | "Distraction management" (across work, not just tasks) |
| **Customer segment** | Different market, same problem | "ADHD students" (instead of professionals)             |
| **Problem**          | Same market, different pain    | "Notification management" (instead of task management) |
| **Platform**         | Business model change          | "Slack plugin" (instead of standalone app)             |
| **Technology**       | Different implementation       | "AI-first" (instead of rules-based)                    |

## Section 9: SCALE PATH (If Persist) (Days 85-90)

**Input**: Confirmed PMF. Now what?

### Pricing Test (Week 12)

**Test with 50 customers**:

- 25 at $50/mo (test price)
- 25 at $30/mo (early bird discount)

**Metric**: Which converts higher? (if $30 converts 2x better, price too high)

**Result**: Refined pricing → ready for sales execution.

### Retention Optimization (Week 12)

**If retention 60-70% day 7, test**:

- Onboarding sequence (help users set up faster)
- In-app nudges (remind to use focus mode)
- Email nurture (send tips on "how others use this")

**Goal**: Push retention from 60% → 70% → 80%

### Leadership Hiring (Weeks 11-12)

**Need**: Sales person or Account Manager to land first 100 customers.

**Profile**: Someone who understands target customer (ADHD makers, ops leaders, product teams).

**Onboarding**: Give them Sales Playbook (see decision-frameworks/sales-playbook.md). Week 1: land 5 customers. Week 2: land 10. Week 3: automate process.

## Section 10: SUCCESS CRITERIA

**PMF Validated** when:

- ☐ 5-8 discovery interviews completed (Mom Test)
- ☐ Positioning statement resonates (4/5 can repeat it)
- ☐ MVP built (3-4 must-have features)
- ☐ 5-8 beta testers recruited
- ☐ Retention >60% day 7 (measured)
- ☐ Retention curves flat/improving day 7-30
- ☐ NPS >50 (customers enthusiastic)
- ☐ Churn <10%/month (sustainable)
- ☐ Pivot vs Persist decision made (data-driven)
- ☐ Pricing tested + refined
- ☐ Ready for sales execution (Sales Playbook ready)

**Day 90 outcome**: PMF validated (persist) or pivot hypothesis refined.
