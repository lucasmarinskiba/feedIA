## Section 7: PIVOT DECISION TREE

**When to pivot** (kill channel, try new one):

```
METRIC BELOW TARGET?
├─ Yes (e.g., engagement <1%, conversion <5%)
│  ├─ Test 1: Change hook/format
│  ├─ Test 2: Change audience
│  ├─ Test 3: Change channel
│  └─ If all 3 tests fail → PIVOT CHANNEL (new channel, same offer)
└─ No (meeting target) → SCALE CHANNEL
```

### Specific Pivot Triggers

| Signal                                             | Action                                                                           |
| -------------------------------------------------- | -------------------------------------------------------------------------------- |
| Engagement rate <1%                                | Test new hook format. If still <1% after 2 weeks, pivot channel.                 |
| Conversion rate <5%                                | Test new CTA. If still <5% after 2 weeks, reposition offer.                      |
| CAC >$100                                          | Verify LTV (customer lifetime value). If LTV <$300, pivot to lower-cost channel. |
| Churn >10%/month                                   | Product issue (not channel issue). Do not pivot channels.                        |
| Leading indicator down (e.g., engagement down 30%) | Leading indicator of future performance. Investigate cause + adjust quickly.     |
