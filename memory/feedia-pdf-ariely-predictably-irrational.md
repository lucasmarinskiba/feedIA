# Dan Ariely — Predictably Irrational (2008)

**Core**: Irracionalidad es sistemática, predecible, explotable. Humanos no racionales — seguimos patrones previstos.

## 13 Irracionalidades Predecibles

1. **Relatividad** — Todo relativo, nunca absoluto. $100 watch caro. Mismo watch al lado $1,000 watch = parece barato. Anchor high first.
2. **Zero-Cost Effect** — FREE = psychological trigger masivo. FREE shipping > ship for $0.01. Activa loss aversion.
3. **Normas Sociales vs Mercado** — Dos mundos. Favores gratis entre amigos. Pedir dinero = transaccional (relación muere). Mezclar = disaster.
4. **Arousal Effect** — Estado emocional (hot/cold) cambia decisiones. Hot = irracional. Cold = lógica. Hormonas override logic.
5. **Procrastinación** — Sabemos procrastinamos ≠ detenemos. Necesitamos estructura externa (deadline, stakes) para actuar.
6. **Sesgo de Propiedad** — Overvalúan lo que poseen. Mug: propietario pide más que no-propietario pagaría. Sunk cost fallacy.
7. **Keeping Doors Open** — Demasiadas opciones = análisis parálisis. Puertas cerradas = enfoque. Más opciones = menos satisfacción.
8. **Expectativas** — Mente obtiene lo que espera. Vino caro tastes mejor (cerebro procesa diferente). Expectativas literal.
9. **Poder del Precio** — Aspirina 50¢ funciona mejor que aspirina 1¢. Precio = señal eficacia. Placebo effect real.
   10-12. **Honestidad + Cash** — Contexto de carácter importa. Hacemos cheat incremental (racionalizamos pequeños robos). Cash = visceral reminder valor.
10. **Behavioral Economics Framework** — No hay free lunch. Irracionalidad sistemática = profitable para quién entiende.
