# Dan Olsen — Lean Product Playbook (2015)

**Core**: Productos fallan = no resuelven customer needs mejor que alternativas. Lean process encuentra PMF sistemáticamente.

**Product-Market Fit**: Producto soluciona real need mejor que alternativas. Customer actively wants/usa. Escalado follows naturalmente.

## 6-Step Lean Process

1. **Determine Target Customer** — Specific persona, not "everyone". Technology adoption lifecycle: Innovators → Early Adopters → Early Majority. Start early adopters.
2. **Identify Underserved Needs** — Customer Benefit Ladders. Importance vs Satisfaction framework. Kano Model: Basic + Performance + Delighters.
3. **Define Value Proposition** — Strategy = saying "no". "We help [customer] achieve [benefit]" vs [alternative]. Test vs REAL competitors.
4. **Specify MVP** — Mínimo para testear value prop. User stories con ROI prioritization. Small batches > big features.
5. **Create Prototype** — MVP = experiment, not mini-product. Fidelity spectrum: low (sketches) → high (code). Qualitative (WHY) vs Quantitative (HOW MANY).
6. **Test with Customers** — 5-8 users per round. Open questions primero. Target customers, not friends.

## Build-Measure-Learn Loop

Hypothesis → Design → Build → Test → Learn → Pivot/Persevere.

**AARRR Metrics**: Acquisition, Activation, Retention, Revenue, Referral. **Retention = kingpin** (si no vuelven, no hay nada).

## Activation

TARGET: Specific persona (not everyone). Early adopters first.
NEEDS: Importance vs Satisfaction. Kano model. Ask en discovery.
VALUE PROP: Strategy = say no. Test vs REAL alternatives.
MVP: Minimum experiment. ROI prioritization.
PROTOTYPE: Fidelity matches test type. Low fidelity = learn WHY.
RETENTION: King metric. If users don't return, you have nothing.
