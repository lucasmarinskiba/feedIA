# Timothy Ferriss — The 4-Hour Workweek (2007)

**Core**: Deferred-life plan = broken. Design lifestyle NOW via DEAL: Define freedom → Eliminate waste → Automate income → Liberate yourself.

## DEAL Framework

**D = Definition** — Perfect lifestyle specific (not generic). Fear-setting = reduce risk anxiety. Systems > motivation.

**E = Elimination** — Parkinson's Law (work expands to time). Compress timeline. 80/20 ruthlessly. Batch interruptions (email 2x/day). Information diet.

**A = Automation** — Outsource repetitive ($5-15/hr VAs). Income autopilot (passive products, licensing). Detach revenue from time input.

**L = Liberation** — Disappearing act (build team without you). Remote work transition. Mini-retirements (1-6 months test lifestyle). Location arbitrage (earn USD, spend emerging markets = 3-4x power).

## Key Concepts

**Relative Income** — $40K/year US ≠ $40K/year Thailand. 3-4x purchasing power abroad.

**Effective vs Efficient** — Doing right things > doing things right.

**New Rich** — Not passive-income-wealthy, but effectively wealthy (time + location + task freedom).

**Not-To-Do List** — What NOT to do = as important as what to do.
