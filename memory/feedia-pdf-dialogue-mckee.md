# Robert McKee — Dialogue (2022)

**Core**: "Dialogue is what characters do to each other." Words perform actions. Character speaks to want/change/defend/attack/seduce/persuade.

**3 Concentric Spheres**:

- **Said** (outer) — Words spoken, surface meanings + connotations
- **Unsaid** (middle) — Thoughts/feelings consciously withheld, revealed by implication
- **Unsayable** (inner) — Subconscious urges beyond words, only expressed through ACTIONS

**3 Tracks**:

1. **Dramatized** — Characters talk TO EACH OTHER in scene (two/multilogue)
2. **Narratized** — Character talks TO SELF (inner monologue) OR TO READER/AUDIENCE (soliloquy, voice-over)
3. **Indirect** — Paraphrase previous scene (no direct dramatization)

**Text vs Subtext**:

- Text = surface behavior/activity (talking, greeting, complimenting)
- Subtext = TRUE ACTION under words (consoling? seducing? insulting?)
- Transparency = text conceals inner life from OTHER characters, reveals it to reader/audience

**3 Functions**:

1. **Exposition** — Pass info (setting, history, character) without stopping momentum
   - Narrative drive (curiosity propels, exposition smuggled background)
   - Exposition as ammunition (characters use knowledge as WEAPON)
   - Revelation from backstory (secrets under pressure = turning point)

2. **Characterization** — Create unique voice (vocabulary, syntax, tone, grammar, accent)
   - Outer traits (believability) + Inner qualities (reveal true character)

3. **Action** — Dialogue carries character DOING something
   - Subtext action = gerund (expressing vulnerability, exerting dominance, testing loyalty)

**Medium Differences**:

- Theatre = heightened language OK, poetic
- Film = naturalistic, image favored
- Prose = full spectrum (poetic to conversational)

**Anti-patterns**: On-the-nose (character explains self), exposition lecture, redundancy (text = subtext no gap), purple prose without character voice.
