# Dialogue — Robert McKee (2022)

**Author**: Robert McKee  
**Core Concept**: "Dialogue is human expression through talk. Words perform actions. Subtext reveals inner life."

## Framework Central

**"Dialogue is what characters do to each other."** (Elizabeth Bowen)

Dialogue ≠ conversation. Dialogue = ACCIÓN VERBAL. Character speaks to want something, change someone, defend/attack/seduce/persuade/confess.

3 Spheres de contenido (concentric circles):

- **Said** (outer): Words spoken, surface meanings
- **Unsaid** (middle): Thoughts/feelings character consciously withholds
- **Unsayable** (inner): Subconscious drives, primal desires beyond words

Skill = crear transparencia: text de palabras conceals inner life from OTHER characters, YET reveals it to reader/audience.

## 3 Tracks de Diálogo

1. **Dramatized**: Characters talk TO EACH OTHER en escena (dos/multilogue)
2. **Narratized**: Character talk TO SELF (inner monologue) or TO READER/AUDIENCE (soliloquy, voice-over)
3. **Indirect Dialogue**: Paraphrase scene anterior (no dramatización directa)

## TEXT vs SUBTEXT

**Text** = palabras dichas (outer behavior, activity).
**Subtext** = acción verdadera bajo las palabras (inner nature, true intention).

**Example**: "Hi, how ya doing? You've lost weight!"

- **Text activity**: Greeting + compliment
- **Subtext action** (depends contexto): Encouraging? Seducing? Taunting? Insulting?

## Functions of Dialogue (3 Pillars)

### 1. EXPOSITION

Pass information (setting, history, character) to reader/audience WITHOUT interrupting scene momentum.

**Techniques**:

- **Narrative drive**: Curiosity propels forward, exposition smuggled in background
- **Exposition as ammunition**: Characters use what they know as WEAPON in scene conflict (not exposition lecture)
- **Revelation from backstory**: Secrets revealed under pressure (lesser-of-two-evils dilemma) create turning points + expose true character

**Anti-pattern**: Characters telling each other facts they already know ("Remember when we met at university 20 years ago?")

### 2. CHARACTERIZATION

Create + reveal unique character voice through dialogue.

**Outer traits** (age, gender, education, accent) + **inner qualities** (morality, intelligence, emotional depth) = character believability.

Character speaks like no one else: vocabulary, diction, syntax, tone, grammar, accent, tropes = ONE-OF-A-KIND VOICE.

### 3. ACTION

Dialogue carries character DOING something: consoling, bribing, seducing, persuading, attacking, defending, confessing, negotiating.

**Subtext action** = gerund phrase ("ing"): character is [expressing vulnerability] / [exerting dominance] / [testing loyalty] / [demanding commitment].

## Content Levels (3 Spheres)

### SAID (Surface)

Words spoken, direct meanings + connotations (cultural symbols, etymology overtones).

**Example**: "Snake" = legless reptile (denotation) + treachery/evil (connotation in Western culture).

Quotable dialogue lives at this level ("I'm just one stomach flu away from my goal weight" — Devil Wears Prada).

### UNSAID (Middle)

Thoughts/feelings character CONSCIOUSLY WITHHOLDS. Reader/audience sense it by implication (subtext).

**Example**: Emily says "I'm just one stomach flu away from my goal weight"

- **Unsaid**: "Fashion industry forces anorexic life. I want career > health. Hunger = acceptable price. You should too if you value job."

### UNSAYABLE (Inner)

Subconscious urges, primal desires beyond conscious articulation. Raw id-level motivations.

Only expressed through ACTIONS, choices under pressure. Can't be spoken directly (character doesn't have words for it).

## Dialogue Forms by Medium

### Theatre

- **Dramatized**: Main mode (actors act scenes with other actors)
- **Narratized**: Soliloquy/aside (character steps out, confides to audience)
- **Language**: Can be verse, poetic, heightened (audiences expect theatrical language)

### Film/TV

- **Dramatized**: Main mode (on-camera dialogue, live-action)
- **Narratized**: Voice-over (off-camera narration) or direct-to-camera (rare, but Deadpool)
- **Language**: Naturalistic, conversational (film favors image over voice)

### Prose

- **Dramatized**: Direct dialogue (quoted verbatim)
- **Narratized**: Inner monologue, first-person narration, stream of consciousness
- **Indirect**: Paraphrase earlier scene dialogue
- **Language**: Full spectrum (poetic/naturalistic/fragmentary)

## Action vs Activity

**Activity** = surface behavior (talking, eating ice cream, sitting).
**Action** = what character ACTUALLY DOING beneath activity.

**Example**: Character eats ice cream.

- **Activity**: Eating ice cream
- **Action**: Drowning sorrows? Rebelling against diet? Rewarding self for sacrifice?

Same activity, multiple actions depending on subtext/motivation.

## Prompt Activación (Dialogue Writing)

```
"Apply Dialogue framework:
- Text vs Subtext: What character SAYS ≠ what character MEANS. Write subtext action (gerund: consoling, exerting, testing)
- 3 Spheres: Said (surface meaning) + Unsaid (implied) + Unsayable (subconscious)
- Function: Is this dialogue exposition (narrative drive, ammunition, revelation)? Characterization (unique voice)? Action (what doing to other)?
- Medium: Theatre = heightened language OK. Film = naturalistic. Prose = full spectrum
- Characters should never explain themselves (on-the-nose). Dialogue should SHOW inner life through implication
- Test: Can reader/audience sense what character is REALLY thinking/feeling beneath words?
- Avoid: Exposition lecture (characters telling each other known facts). Redundancy (text = subtext, no gap). Purple prose (prose CAN be poetic, but must serve character voice)"
```

## Vocabulario Técnico

| Término                      | Definición                                                                        |
| ---------------------------- | --------------------------------------------------------------------------------- |
| **Dramatized Dialogue**      | Characters talk TO EACH OTHER en escena (verbatim dialogue quoted)                |
| **Narratized Dialogue**      | Character talk TO SELF (inner monologue) or TO AUDIENCE (voice-over, soliloquy)   |
| **Subtext**                  | Acción verdadera BAJO las palabras (diferente de text/surface meaning)            |
| **True Character**           | Quien es character realmente (revealed through choices under pressure, NOT words) |
| **On-the-nose Dialogue**     | Character says exactly what thinks/feels (kills subtext, feels inauthentic)       |
| **Exposition as Ammunition** | Character usa lo que sabe como WEAPON en scene (no lecture mode)                  |
| **Performative**             | Words that perform task (J.L. Austin): saying = doing                             |
