# Dan Olsen — Lean Product Playbook (2015)

**Core**: Products fail because they don't meet customer needs better than alternatives = lack product-market fit. Lean process finds fit systematically.

**Product-Market Fit**: Product solves real customer need better than alternatives. Customer actively wants/uses it. Scale follows naturally.

## Lean Product Process (6 Steps)

### 1. DETERMINE TARGET CUSTOMER

- Not "everyone". Specific persona.
- Fishing for customers in wrong pond = waste.
- Technology Adoption Lifecycle: Innovators → Early Adopters → Early Majority
- Start with early adopters (less picky, more forgiving).

### 2. IDENTIFY UNDERSERVED CUSTOMER NEEDS

- Customer Benefit Ladders: What benefits matter? Hierarchy of needs.
- Importance vs Satisfaction Framework: Which needs are important but unsatisfied?
- Test with customer discovery interviews. Mom Test applies.
- Kano Model: Basic needs + Performance needs + Delighters.

### 3. DEFINE VALUE PROPOSITION

- Strategy = saying "no". What are you NOT doing?
- Articulate: "We help [customer] achieve [benefit]" vs [alternative].
- Test against real competitors (not imaginary).
- Example: Google vs Yahoo = speed + simplicity beat feature-rich.

### 4. SPECIFY MINIMUM VIABLE PRODUCT (MVP)

- What's minimum to test value proposition?
- User stories: "As [user], I want [feature] so that [benefit]"
- Prioritize by ROI (customer value ÷ implementation cost).
- Small batch sizes > big features.

### 5. CREATE MVP PROTOTYPE

- MVP = experiment, not mini-product.
- Fidelity spectrum: low (sketches) → high (working code).
- Matrix: Qualitative vs Quantitative × Marketing vs Product tests.
- Qualitative = learn WHY. Quantitative = measure HOW MANY.

### 6. TEST WITH CUSTOMERS

- User testing: 5-8 users per round (diminishing returns).
- Open vs closed questions. Ask open first.
- Recruit target customers (not friends).
- Capture feedback, synthesize, iterate.

## Build-Measure-Learn Loop

- Hypothesize → Design → Build → Test → Learn → Iterate
- Persevere OR Pivot based on metrics.
- AARRR Metrics: Acquisition, Activation, Retention, Revenue, Referral.
- Retention is the kingpin (if they don't come back, you have nothing).

## Anti-Patterns

- ❌ Building without customer validation
- ❌ Wrong target customer (fishing in wrong pond)
- ❌ Feature-first (build what sounds cool, not what solves)
- ❌ No metrics (vanity metrics = worthless)
- ❌ One test = done (iterate minimum 3 rounds)
