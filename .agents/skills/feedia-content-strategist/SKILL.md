# FeedIA Content Strategist Agent

**Core**: Content strategy = positioning (context) + growth channels (distribution) + offer (value) + virality (engagement).

## Mission

Generate 30/60/90-day content strategy for brand. Output: Hook types, posting calendar, hooks/captions, engagement tactics.

## Orchestration Flow

```
CLIENT INPUT
↓ Brand: [name]. Offer: [what you sell]. Target: [customer]. Channel: [Instagram/TikTok]
↓
OFFER ARCHITECTURE SKILL
↓ Define positioning (5 components) + customer hero narrative + influence stack
↓ Output: Offer blueprint (context → narrative → trust → price → psychology)
↓
GROWTH ENGINE SKILL
↓ Select 3 winning channels (Bullseye). Define growth target. Anchor psychology.
↓ Output: Channel prioritization + anchor strategy
↓
POSITIONING CONTEXT
↓ Mental ladder: "What category is this brand in?" Define market frame.
↓
STICKY IDEAS (Heath SUCCESs)
↓ Simple + Unexpected + Concrete + Credible + Emotional + Stories
↓ Convert offer into sticky idea (1-sentence hook)
↓
STEPPS VIRALITY (Berger)
↓ Social currency + Triggers + Emotion + Public + Practical + Stories
↓ Embed into content pillars
↓
CONTENT PILLARS (OUTPUT)
Pillar 1: Offer positioning (hero narrative)
Pillar 2: Social proof (community proof)
Pillar 3: Viral mechanics (STEPPS)
Pillar 4: Product/service showcase
↓
POSTING CALENDAR + HOOKS
↓ 30 days: 5 hook types (20 posts). 60 days: 10 hook types (40 posts). 90 days: 15 hook types (60 posts).
↓
CONTENT STRATEGY COMPLETE
```

## Agent Prompts

### Prompt 1: POSITIONING ANALYSIS

```
"Analyze positioning for [BRAND]:
- 5 Components (Dunford): What are competitors? Unique attributes? Value theme? Target? Market category?
- Mental Ladder: What category does customer think? Where does [BRAND] sit?
- Output: Positioning statement (1 sentence). Market frame (how to think about category)."
```

### Prompt 2: OFFER → STICKY IDEA

```
"Convert offer to sticky hook (Heath SUCCESs):
- SIMPLE: Core benefit in 7 words max.
- UNEXPECTED: What breaks pattern?
- CONCRETE: Specific detail (number/example).
- CREDIBLE: Proof/credential (number, third-party, founder, stat).
- EMOTIONAL: Why does customer care? (fear, joy, love, trust).
- STORY: Trojan horse (customer transformation story).
Example: 'Save 10 hours/week via AI-powered task batching. Join 500+ solopreneurs already shipping twice as fast.'
Output: Sticky hook statement."
```

### Prompt 3: STEPPS VIRALITY FRAMEWORK

```
"Design viral hook using STEPPS (Berger):
- Social Currency: How does sharing make customer look? (status, insider knowledge, generosity).
- Triggers: Link to frequent cue (morning coffee, email, commute).
- Emotion: High arousal (awe, ire, excite, inspire). NOT low (sad, content).
- Public: Behavioral residue (others see you use it). Visible sharing.
- Practical Value: Info useful → shareable (tip, template, stat).
- Stories: Trojan horse (product reveal via transformation story).
Output: Viral mechanism mapped to hook."
```

### Prompt 4: CHANNEL STRATEGY

```
"Define growth strategy (Ferriss DEAL + Weinberg Bullseye):
1. DEFINITION: Growth target specific (100 followers? 10K? 100K?). Timeline.
2. ELIMINATION: Which 80% of tactics NOT to do? Time budget per week.
3. CHANNEL BULLSEYE: Test 3 channels (2-week sprints each). Winner = focus.
4. AUTOMATION: Batch content (4 weeks at once). Outsource edits/posting.
5. LIBERATION: System runs without founder (scheduler, VA editing, auto-responses).
Output: Channel + cadence + time commitment."
```

## 30/60/90 Day Template

### 30 Days: FOUNDATION

- 5 hook types (4 posts each = 20 total)
- Type 1: Problem-Agitation-Solution (PAS)
- Type 2: Curiosity gap
- Type 3: Social proof (testimonial)
- Type 4: Behind-the-scenes (relatability)
- Type 5: Viral (STEPPS)
- Posting: Daily (1 post/day, batch created)
- Engagement: Reply all comments (community)
- Metrics: Reach, engagement rate, follower growth

### 60 Days: EXPANSION

- 10 hook types (4 posts each = 40 total)
- Add Type 6: Comparison (vs competitor)
- Add Type 7: Data-driven (stat + trend)
- Add Type 8: Founder story (authority)
- Add Type 9: Transformation (before/after)
- Add Type 10: Call-to-action (CTA) focused
- Posting: Daily + Stories (3 stories/day)
- Engagement: DMs + community challenges
- Metrics: Reach + saves + shares

### 90 Days: OPTIMIZATION

- 15 hook types (4 posts each = 60 total)
- Add Type 11: Controversial (contrarian take)
- Add Type 12: Tutorial (practical value)
- Add Type 13: Trend jacking (news relevance)
- Add Type 14: Collaboration (guest feature)
- Add Type 15: Community proof (UGC)
- Posting: Daily + Reels (3x/week) + Stories (daily)
- Engagement: Affiliate program launch + ambassador recruitment
- Metrics: Reach + saves + shares + conversions

## Example Build

**Brand**: SaaS (AI task manager for ADHD)

### Positioning (Dunford)

- Competitors: Asana, Todoist, Notion, paper
- Unique: ADHD-specific UX (simplified, distraction-free)
- Value theme: "Focus via simplicity"
- Target: ADHD women 25-40 remote
- Category: "ADHD-friendly productivity"

### Sticky Idea (Heath)

"Stop task overwhelm. Ship twice as fast with distraction-free task management built for ADHD brains. Join 1000+ makers."

### STEPPS Virality

- Social Currency: "ADHD founder building for ADHD users" (authenticity + insider)
- Triggers: Morning routine (remind when waking up)
- Emotion: Relief + empowerment (high arousal)
- Public: Dashboard visible (show in Slack, Twitter screenshots)
- Practical: ADHD productivity tips (free template + research)
- Stories: "How I went from 0 tasks to shipping 5 products/year" (trojan horse)

### Channel Strategy

- Growth target: 10K followers 90 days
- Time budget: 5 hours/week (batch content 4h, engage 1h)
- Channels: TikTok (primary) + Instagram Reels (secondary) + Twitter (thought leadership)
- Winner (projected): TikTok (highest reach + viral potential for ADHD audience)
- Automation: VA edits clips, scheduler posts, templates pre-built
