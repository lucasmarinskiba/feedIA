# Gary Vaynerchuk — Jab, Jab, Jab, Right Hook (2013)

**Core**: Platform-native content strategy. One-size-fits-all social strategy = failure. Facebook ≠ Twitter ≠ Instagram ≠ Pinterest.

**Metaphor**:

- **Jab** = Provide value, entertainment, utility (content they want)
- **Right Hook** = Pitch, call-to-action, ask for sale (content you want them to do)
- Ratio: Multiple jabs before each right hook. Not 1:1. Ratio ~70:30 value:pitch.

## Platform-Native Rules (≠ Same Everywhere)

### Facebook

- **Format**: Stories, personal updates, longer-form video
- **Jab**: Behind-the-scenes, family moments, authentic narrative, community
- **Right Hook**: Event invites, Page Likes, link clicks, shares
- **Timing**: Lunch hour, evening (people scroll on desktop/mobile differently)
- **Tone**: Conversational, personal, not corporate

### Twitter

- **Format**: Real-time, short bursts, hot takes, conversations
- **Jab**: News reaction, industry insight, humor, personality
- **Right Hook**: Retweet engagement, follow request, link to destination
- **Timing**: Morning commute, lunch, evening news cycle
- **Tone**: Opinionated, fast, interactive (talk TO people, not AT)

### Pinterest

- **Format**: High-quality images, inspiration, long shelf-life
- **Jab**: Aspirational imagery, DIY, tutorials, mood boards, lifestyle
- **Right Hook**: Pin to website/product, click link, save board
- **Timing**: Off-hours (Pinterest is evergreen, not real-time)
- **Tone**: Visual > text. Curated. Inspirational.

### Instagram

- **Format**: Premium visual, square focus, stories, captions as context
- **Jab**: Aesthetic imagery, behind-scenes, lifestyle, education (short video)
- **Right Hook**: Follow, bio link, swipe-up (if eligible), direct message
- **Timing**: Morning scroll, evening (habits matter)
- **Tone**: Visual-first. Captions are supporting character, not star.

### Tumblr

- **Format**: Reblog culture, memes, long-form text posts, fandoms
- **Jab**: Shareable content, commentary, community inside jokes, aesthetic
- **Right Hook**: Follow, ask for questions, subtle brand integration
- **Timing**: Late evening (younger demographic)
- **Tone**: Authentic, weird, part-of-community (not brand-corporate)

## Core Principles

**No Universal Social Strategy**:

- Content that crushes on Facebook might flop on Twitter
- Posting schedule optimal for one platform ≠ optimal for all
- Native features matter (Stories, Retweets, Repins, Shares — use them)

**Listen First, Broadcast Second**:

- Before posting jabs, listen to your audience on each platform
- They tell you what they want. Match it.

**Story Over Follower Count**:

- 10,000 engaged followers > 1M fake followers
- Engagement = listen to feedback + respond + iterate

**Give Before You Ask**:

- Build trust with jabs before right hooks
- If only right hooks, people mute/unfollow
- If only jabs, no business (need some right hooks)

## Activation for Agents

```
"Apply platform-native storytelling:
FACEBOOK: Personal narrative + stories. Evening timing. Community-first. Right hook = events/pages.
TWITTER: Real-time opinion + conversation. Morning/lunch/news cycle. Talk TO not AT. Right hook = engagement/follows.
PINTEREST: Aspirational imagery. Long shelf-life. Tutorials/mood boards. Right hook = click-throughs to destination.
INSTAGRAM: Premium visuals lead. Captions support. Stories + feed. Right hook = bio link, follow, DM.
TUMBLR: Community culture + memes. Late evening. Authentic weird. Right hook = followers, asks.
RATIO: 70% jab (value) + 30% right hook (pitch).
LISTEN: Audience tells you what works per platform. Iterate.
Anti-patterns: Same content everywhere, only jabs (no business), only right hooks (no trust), ignoring platform native features."
```
