# SKILL: Habit-Forming Products

## Source: Nir Eyal — "Hooked: How to Build Habit-Forming Products" (2014)

---

## PRINCIPIO CENTRAL

Los productos más poderosos no necesitan publicidad. Forman hábitos. El usuario regresa solo, sin recordatorio externo.

**Dato de apertura**: 79% de usuarios de smartphone revisan el dispositivo en los primeros 15 minutos de despertar. No porque alguien les dijo — porque es hábito.

---

## EL HOOK MODEL (4 FASES)

```
TRIGGER → ACTION → VARIABLE REWARD → INVESTMENT → [loop]
```

Cada ciclo completo refuerza el hábito. A más ciclos, más profunda la ranura neural.

---

### FASE 1 — TRIGGER (Disparador)

El detonante de la conducta. Dos tipos:

**A) External Triggers** — señales del entorno

| Tipo         | Ejemplo                       | Costo         |
| ------------ | ----------------------------- | ------------- |
| Paid         | Ads, SEM                      | Alto, escala  |
| Earned       | PR, viral, SEO                | Gratis, lento |
| Relationship | Recomendación boca-a-boca     | Gratis, lento |
| Owned        | App icon, email, notificación | Casi gratis   |

**B) Internal Triggers** — emociones que activan el producto sin señal externa

- Emociones **negativas** son los triggers más poderosos: aburrimiento, soledad, ansiedad, miedo, incertidumbre, FOMO
- El objetivo: el producto se asocia a una emoción interna → usuario lo busca sin ser llamado
- Ejemplos: "me aburro" → abro Instagram. "me siento solo" → abro Facebook. "tengo una duda" → busco en Google.

**Regla**: Productos que resuelven emociones negativas frecuentes ganan. Los primeros en la mente ganan.

---

### FASE 2 — ACTION (Acción)

La conducta más simple posible en anticipación de una recompensa.

**Fogg Behavior Model: B = MAT**

```
Behavior = Motivation × Ability × Trigger
```

Los tres deben estar presentes simultáneamente.

**Motivators** (pares opuestos que aumentan/reducen probabilidad de acción):

- Placer / Dolor
- Esperanza / Miedo
- Aceptación social / Rechazo

**Ability** (cuánto cuesta hacer la acción — reducir todo):

- Tiempo requerido
- Dinero requerido
- Esfuerzo físico
- Carga cognitiva (brain cycles)
- Desviación social (¿es "raro" hacerlo?)
- Fuera de rutina

**Regla de oro**: No motives más → simplifica más. La facilidad supera a la motivación.

---

### FASE 3 — VARIABLE REWARD (Recompensa Variable)

Lo que distingue el Hook Model de un simple feedback loop: la **variabilidad**.

**Por qué funciona**: La dopamina sube más cuando se _anticipa_ una recompensa que cuando se recibe. La variabilidad multiplica ese efecto. El cerebro entra en estado de búsqueda (wanting) suprimiendo el juicio racional.

**3 tipos de Variable Reward**:

| Tipo                     | Mecanismo                                     | Ejemplos                                         |
| ------------------------ | --------------------------------------------- | ------------------------------------------------ |
| **Rewards of the Tribe** | Validación social, conexión, pertenencia      | Likes, comments, retweets, views, reconocimiento |
| **Rewards of the Hunt**  | Recursos, información, dinero, descubrimiento | Scroll infinito, búsqueda, e-commerce, juegos    |
| **Rewards of the Self**  | Logro, competencia, maestría, completar       | Gamificación, badges, streaks, progreso visible  |

**Regla**: La recompensa predecible no crea deseo. La incertidumbre sí. Slot machine > vending machine.

---

### FASE 4 — INVESTMENT (Inversión)

El usuario pone algo de sí mismo en el producto: tiempo, datos, esfuerzo, capital social, contenido, dinero.

**Por qué importa**:

1. Almacena valor que se pierde si abandona (switching cost)
2. Mejora el producto para el próximo ciclo (trigger más relevante, acción más fácil, recompensa más rica)
3. Crea anticipación del próximo ciclo

**Formas de inversión**:

- Contenido creado (posts, mensajes, colecciones)
- Datos de preferencias (historial, favoritos)
- Seguidores / red social acumulada
- Reputación y credibilidad
- Aprendizaje de la interfaz

**Ejemplo**: Gmail → historial de emails inmenso → costo altísimo de migrar. Twitter → followers acumulados → dejar significa perderlos. Pinterest → pines guardados → tu colección desaparece si te vas.

**LIFO para nuevos hábitos**: Los hábitos más recientes son los primeros en caer. Para que un nuevo hábito persista, el producto debe capturar inversión desde el primer ciclo.

## THE HABIT ZONE

Dos ejes:

- **Frecuencia** (qué tan seguido ocurre la conducta)
- **Utilidad percibida** (qué tan valioso es vs. alternativas)

Un comportamiento entra en la "Habit Zone" cuando frecuencia × utilidad percibida superan el umbral necesario para convertirse en respuesta automática.

- **Google**: frecuencia altísima + utilidad baja por evento (cualquier buscador es similar) → hábito automático
- **Amazon**: frecuencia media + utilidad percibida muy alta (todo en un lugar, confianza) → hábito estratégico

**Regla**: Sin frecuencia suficiente, ningún nivel de utilidad crea hábito. La acción debe ocurrir repetidamente para neuralizarse.

## VITAMINAS vs ANALGÉSICOS

**Inversores preguntan**: "¿Construyes vitamina o analgésico?"

La respuesta para habit-forming products: **ambos**.

| Fase        | Tipo       | Descripción                                     |
| ----------- | ---------- | ----------------------------------------------- |
| Pre-hábito  | Vitamina   | Nice-to-have, no urgente, fácil de omitir       |
| Post-hábito | Analgésico | Must-have, ausencia duele, imposible de ignorar |

**"Un hábito es cuando no hacer la acción causa un poco de dolor."**

El pain no es literal — es el "itch" de no tener el producto cuando el trigger interno dispara.

## BENEFICIOS DE NEGOCIO DEL HÁBITO

### 1. Mayor Customer Lifetime Value (CLTV)

Los usuarios habituales compran más, más seguido, por más tiempo.

### 2. Flexibilidad de Precio

Warren Buffett: "Puedes medir la fortaleza de un negocio por cuánta agonía sienten al subir precios." Los usuarios habituales son menos price-sensitive → mayor margen.

### 3. Crecimiento acelerado

- Hábito → evangelismo → boca-a-boca
- Más usuarios activos diariamente → Viral Cycle Time más corto
- Facebook vs MySpace: más daily actives → más triggers sociales → más invitaciones → más loops

### 4. Ventaja competitiva (moat)

- El competidor necesita ser 9x mejor para romper un hábito (John Gourville, Harvard Business School)
- QWERTY sigue dominando 150+ años después — no porque sea mejor, sino porque el costo de cambio es real
- Inversiones acumuladas hacen el switching imposible

## MATRIZ MORAL — MANIPULATOR'S MATRIX

Antes de usar el Hook Model, cada builder debe responder:

1. ¿Usaría yo mismo este producto frecuentemente?
2. ¿Creo que este producto mejora la vida de quien lo usa?

| Usa el producto | Cree que mejora | Rol                     |
| --------------- | --------------- | ----------------------- |
| ✓               | ✓               | **Facilitador** — ideal |
| ✗               | ✓               | Vendedor (Peddler)      |
| ✓               | ✗               | Entretenedor            |
| ✗               | ✗               | Dealer — evitar         |

**Distinción crítica**: Hábito ≠ adicción. Adicción = dependencia persistente y autodestructiva. Hábito puede ser positivo (ejercicio, flossing, leer). Construir hábitos negativos es irresponsable.

## PROMPT DE ACTIVACIÓN PARA AGENTES

```
"Apply Hooked / Hook Model framework:
TRIGGER: Identify the internal trigger (emotion: boredom/loneliness/anxiety/FOMO/uncertainty)
  that cues product use. Design external triggers (notifications/icons/emails) that teach the internal association.
ACTION: Apply B=MAT. Reduce friction to minimum viable effort. Motivation tactics only after ability maximized.
VARIABLE REWARD: Mix Tribe (social) + Hunt (discovery/resources) + Self (achievement/mastery).
  Never make reward fully predictable. Maintain uncertainty = maintain dopamine anticipation.
INVESTMENT: Design early investments that store value, improve next cycle, and create switching costs.
  Data, content, social capital, and reputation all work.
HABIT ZONE: Frequency × Perceived Utility. If frequency too low, NO habit. Push daily/weekly use.
VITAMINS→PAINKILLERS: Product starts nice-to-have, becomes must-have through habit. Design for that arc.
BUSINESS: CLTV + pricing power + viral loop + competitive moat = habit-driven value.
ETHICS: Builder must use own product + believe it improves lives. Habit ≠ addiction.
ANTI-PATTERNS:
  ❌ External triggers without path to internal trigger association
  ❌ Predictable, fixed rewards (no dopamine spike)
  ❌ High-friction actions (kills action phase)
  ❌ No investment mechanic (no switching cost, no improvement loop)
  ❌ Low frequency use without compensating high perceived utility"
```

## VOCABULARIO TÉCNICO

| Término          | Definición                                                                   |
| ---------------- | ---------------------------------------------------------------------------- |
| Hook Model       | Framework 4 fases: Trigger → Action → Variable Reward → Investment           |
| External Trigger | Señal externa (notificación, email, icono, anuncio) que inicia la conducta   |
| Internal Trigger | Emoción o pensamiento que cues el producto sin señal externa                 |
| Variable Reward  | Recompensa impredecible que genera dopamina anticipatoria y deseo            |
| Investment Phase | Acciones del usuario que almacenan valor y mejoran el próximo ciclo del hook |
| Habit Zone       | Zona donde frecuencia × utilidad percibida crean conducta automática         |
| B = MAT          | Behavior = Motivation × Ability × Trigger (Fogg Behavior Model)              |
| Switching Cost   | Valor acumulado en un producto que se pierde al abandonarlo                  |
| Viral Cycle Time | Tiempo que tarda un usuario en invitar a otro usuario                        |
| CLTV             | Customer Lifetime Value — valor total de un cliente antes de que abandone    |
| Rewards of Tribe | Recompensas sociales: likes, comentarios, reconocimiento, pertenencia        |
| Rewards of Hunt  | Recompensas de descubrimiento: info, recursos, dinero, contenido variable    |
| Rewards of Self  | Recompensas internas: logro, maestría, completar, progreso visible           |
